CIPTA AROMA KREASI — WEBSITE COMPANY PROFILE

Isi folder:
- index.html : halaman Home, menu 6 minuman, Best Seller 2 produk, diagram penjualan, dan kontak.
- about.html : halaman About Us, cerita perusahaan, visi, misi, dan nilai-nilai brand.
- style.css  : desain visual dan pengaturan responsif desktop/HP.
- script.js  : navigasi hamburger pada HP dan diagram penjualan berbasis Canvas.

Cara menjalankan di Visual Studio Code:
1. Ekstrak ZIP ke folder pilihan.
2. Buka folder cipta_aroma_kreasi di Visual Studio Code.
3. (Disarankan) Pasang ekstensi Live Server.
4. Klik kanan index.html lalu pilih "Open with Live Server".
5. Navigasi Home dan About Us saling terhubung. Tautan Menu dan Best Seller dari halaman About Us akan menuju bagian yang sesuai di Home.

Catatan penting:
- Gambar menu/latar dan font diambil dari Unsplash dan Google Fonts, sehingga memerlukan koneksi internet.
- Harga, kontak, akun Instagram, tahun, dan grafik penjualan adalah data contoh. Silakan ubah sesuai informasi perusahaan sebenarnya.
- Diagram menggunakan data contoh: 145, 170, 185, 205, 245, 320 gelas untuk Januari–Juni.
